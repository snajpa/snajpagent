Release highlights

0.99.8c · October 2, 2026

  • Session names, resume selection and grouped listings preserve saved options and live ownership.
  • Terminal attachment coordinates input and audio activation with the destination frontend while managed work keeps running.
  • Context recovery retains completed tool results, request prefixes and retry notices across compaction and provider changes.
  • Voice captions accumulate transcript fragments, and voice stays enabled through work and recoverable failures.
  • Native remote mode transfers files in both directions through SSH or Mosh, with a durable download outbox.
  • Device audio and native voice backends are included across the matrix.

0.99.8b-d25f0846 · September 29, 2026 · Development

  • Fixes OpenAI API-key token-count requests rejected for include, including compaction preflight.
  • Improves terminal attachment, retained history and voice conversation continuity across long sessions.
  • Enables device audio and native voice backends in Linux, macOS, Windows and BSD builds.

0.99.8b · September 27, 2026

  • Long sessions recover from repeated context and media limits while retaining completed tool work and attachments.
  • The prompt keeps context usage current, and submitted input remains visible while the next composer waits.
  • Regular files upload through the wrapped terminal or /upload and stay private until sent.
  • Model-tool selection uses current provider catalog entries; the stable updater recognizes 0.99.8b.

0.99.8 · September 23, 2026

  • Long provider turns recover from context and image-input limits without replaying completed tool calls.
  • Resume and model switching retain the selected binding, pending work and bounded access to durable history.
  • The composer echoes submitted input promptly; IRC steering and managed-command outcomes remain ordered and recoverable.
