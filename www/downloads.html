Install on macOS

Rename the chosen executable to snajpagent and compare its hash with the row above. For an archive, check the archive before extracting it; the displayed hash belongs to the downloaded file.

shasum -a 256 ./snajpagent
chmod +x ./snajpagent
./snajpagent

If macOS blocks the downloaded file, and you trust it, remove quarantine from that executable only, then launch it:

xattr -d com.apple.quarantine ./snajpagent
./snajpagent

For a debug archive, use shasum -a 256 FILE.tar.gz, compare it with the archive's row, then tar -xzf FILE.tar.gz. Apply the launch steps to the extracted snajpagent. These builds are not Developer ID signed or notarized. Keep system-wide macOS protections enabled.

Stable 0.99.2 and later install updates in the background. Set auto_update = false in [agent] to opt out. Development snapshots default off; set it to true to follow latest-dev. Version 0.99.1 updates manually.

Release log

0.99.3 — September 8, 2026
Broader BSD support and tag-driven releases.
- Add OpenBSD and NetBSD downloads; extend legacy FreeBSD to 5.1.
- Build and stage releases directly from the approved Git tag.
- Simplify runtime ownership and fix old-BSD edge cases.

0.99.2 — September 8, 2026
Background updates and clearer streamed Markdown.
- Install matching binaries in the background; restart when convenient.
- Keep plain-text fences unlabeled and their contents literal.
- Add legacy Linux and both FreeBSD binary variants.

0.99.2-9d98036 — September 8, 2026 — development
Debug snapshot of the background-update release.
- Retain application debug information on every platform.
- Follow latest-dev when automatic updates are explicitly enabled.

0.99.1 — September 7, 2026
First standalone binary release.
- Download Linux, macOS and Windows executables with TLS roots included.
- Browse the complete manual and use clearer queue controls.
