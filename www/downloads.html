On Linux, macOS or BSD, rename the downloaded file to snajpagent, run chmod +x snajpagent and keep it in a user-owned directory. On Windows, keep the .exe extension. Run it in your project directory to set up a provider.

Stable binaries install updates in the background. The running process continues using its original version; one banner tells you when to restart. Set auto_update = false in [agent] to opt out. See the manual for update URLs, permissions and recovery.

Requirements

  • Linux: the standard builds require a modern Linux kernel. The separate i686 legacy build supports Linux 2.4.27 with procfs and secure OS entropy; PTY commands also need devpts.
  • macOS: experimental; macOS 11 or later. Universal includes Intel and Apple Silicon. ARM64 is ad-hoc signed; Intel is unsigned. Neither is Developer ID signed or notarized.
  • Windows: experimental x64 and ARM64 builds using Windows system DLLs; ARM64 needs the OS UCRT.
  • FreeBSD: amd64 with the libc.so.7 ABI, including 8.4 and 14.4. The separate legacy build uses FreeBSD 5.1/5.5's libc.so.5 and libc_r.so.5 ABI.
  • OpenBSD: experimental amd64 executables for 7.9, 5.9 and early 3.5. Choose the exact OS variant.
  • NetBSD: experimental amd64 executables for 10.1 and legacy 5.2.3, with separate native thread-library ABIs.

Additional source builds

NetBSD amd64: use make prod-netbsd-amd64 for 10.1 or make prod-netbsd-amd64-legacy for 2.0 and 5.2.3. These experimental builds use separate native pthread ABIs. Build instructions are in the manual.
