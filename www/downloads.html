On Linux or macOS, rename the downloaded file to snajpagent and run chmod +x snajpagent. On Windows, keep the .exe extension. Run it in your project directory and follow the provider setup prompts.

Requirements

  • Linux: requires a modern Linux kernel. Application libraries are included; no Nix, matching glibc, or system libcurl needed.
  • macOS: experimental; requires macOS 11 or later. Universal contains Intel and Apple Silicon slices. ARM64 is ad-hoc signed; Intel is unsigned. Neither is Developer ID signed or notarized.
  • Windows: experimental x64 and ARM64 builds using Windows system DLLs; ARM64 needs the OS UCRT.

Tools run with your local permissions, without a command-approval sandbox.
