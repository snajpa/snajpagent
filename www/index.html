snajpagent

A fast, lightweight, networked coding agent for your terminal.

Work with a model in your project. Steer it while it runs. Bring people and agents together through native IRC chat.

1. Rollout · 2. Network · Install · Source · README

1. Work in rollout

Start snajpagent in your project, describe a change, and press Enter. Rollout is your local working view. A turn is the work started by one prompt, including tool use. Model responses appear here; /verbose 1 adds tool activity.

While a turn runs:

  • Enter steers now: “Keep the public API unchanged.”
  • Tab queues later: “Then add a regression test.”

Tab tries completion first. Queued prompts do not enter the current turn; after it finishes, they run oldest first. The rollout prompt shows the pending count. /queue lists them; /queue 2 edit revises one.

Interrupted or failed work leaves the queue paused. After session resume, queued turns also wait: use /next while idle.

Ctrl-J adds a newline. Ctrl-C clears a draft; with an empty draft it interrupts work. /goal finish this change continues across turns until complete or blocked; /goal pause pauses continuation at a turn boundary.

2. Work together over the network

Each session has an operator and model nick. They share a room, while each session keeps its own workspace, tools, and rollout. In separate terminals:

snajpagent -s -n builder -o alice -r work
snajpagent -c -n reviewer -o bob

The first hosts #work; the second joins at localhost:6667. -n names the model; -o names its operator.

Chat is the shared conversation. Enter sends to the room; mention @builder to ask that model to work or steer it. Models explicitly publish through irc_send; other output stays local unless they choose to share it.

Empty Tab switches chat ↔ rollout, even offline. /chat and /rollout select either view. Switching does not stop work; returning displays buffered output. With text, Tab completes commands and chat nicks first, otherwise queues during work or indents while idle. Queueing stays local, even in chat.

IRC has no authentication or TLS: use localhost, a trusted network, or a secure tunnel. Tools run with your permissions, without an approval sandbox.

Install

Build with C11/POSIX, pthreads, GNU make, libcurl, and Jansson. See README for platform dependencies.

git clone https://github.com/snajpa/snajpagent.git
cd snajpagent
make
sudo make install
cd /path/to/your/project
snajpagent

Without configuration or credentials, first interactive launch offers provider setup. Authenticate and choose a supported model.
