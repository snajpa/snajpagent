snajpagent

A fast, lightweight, networked coding agent for your terminal.

Ask an AI model to work on a project. It can inspect files, make changes, and run commands. Correct it while it works or line up the next task. Native IRC chat lets people and agents work together, each with their own workspace and local conversation.

Everything runs in a normal scrolling terminal. There is no background service: exit to stop work, then reopen the saved conversation when you return.

1. Start a task in rollout

After installation and provider setup, start in the project directory you want to change. This is your workspace.

cd /path/to/your/project
snajpagent

Describe a task and press Enter: “Fix the empty-input bug, keep the public API unchanged, and run the tests.” The prompt and the work it starts make up a turn. The model may use several tools before giving a final answer.

Rollout is the local view of that conversation and work. It opens first when no networking is configured. Text beginning with / is a command to snajpagent rather than a request to the model. Type /help and press Enter to see the controls.

By default you see model text. /verbose 1 adds compact tool activity; /verbose 2 adds previews of tool inputs and results. You can change this while the model works.

Correct this task or queue the next one

You can type while work is active. Your unsent text is a draft; typing alone does not interrupt anything.

Enter steers the current turn. “Use the existing parser; don't add a dependency” interrupts the model's response and continues with your correction. Commands that have already started keep running.

Tab at the end of an ordinary message queues a later turn. “Then add regression coverage” waits until current work finishes. Waiting prompts run oldest first, one at a time—not as parallel agents.

(N) in the prompt counts waiting turns. /queue lists them. /queue 2 edit opens item 2 for editing; Enter saves it and Ctrl-C abandons the edit. /queue 2 delete removes it. After a pause or session resume, /next restarts the queue while idle.

Tab completes only when you ask it to

Start the draft with /: type /sta, then Tab, to complete /status. A unique match adds a space; press Enter to run the command. Ordinary words do not trigger command completion. With several matches, a second Tab lists choices; no match leaves the draft unchanged.

In chat, Tab also completes nickname words beginning with @, as shown below. Completion never sends or queues text. Outside a completion, Tab queues while work is active and inserts spaces while idle. Empty Tab switches views.

Stop, resume, or keep going with a goal

Ctrl-J inserts a newline. Up/Down recall prompts and Ctrl-R searches history. Ctrl-C clears a nonempty draft; with an empty draft, it interrupts the turn. Ctrl-D on an empty draft exits.

A session saves the conversation, settings, tool results, queue, and goal. Normal exit prints the command to reopen it. snajpagent --resume --last also reopens the newest session for your workspace.

A normal final answer ends the turn. To keep working across turns, set a goal: /goal fix the bug and validate the change. It continues until complete, paused, cancelled, or blocked. Queued prompts come first.

/goal pause pauses automatic continuation at a turn boundary. Exiting stops the program but preserves an active goal: it continues on resume. Pause it first if you want it to stay paused.

2. Work together over the network

IRC is a chat protocol built into snajpagent. One instance hosts a room; another joins it. Each session has two chat names, or nicks: one for the operator (you) and one for its model.

snajpagent -s -n builder -o alice -r work
snajpagent -c -n reviewer -o bob

Run these in separate terminals. The first hosts #work at localhost:6667; the second joins on the same machine. -n names the model and -o names its operator.

Shared chat, local rollout

Networked startup opens chat, the shared room conversation. Enter sends as your operator nick. Mention @builder to ask that model to work or steer it at a safe boundary. Unaddressed conversation is background context, not a new task.

Models use irc_send to publish chosen replies. Their other text and tool activity stay in rollout. Empty Tab switches between the views without stopping work; /chat and /rollout select one directly.

Complete a name, then choose where to send

Type @bu and press Tab. If the match is unique, it becomes @builder with a space. Keep typing: @builder check the empty-input case.

Enter sends the finished message to the room. Tab at its end, while your local model is active, queues a local follow-up instead. An @ name can appear later in a sentence too. With the cursor still in that name, Tab completes it first.

/names lists rooms and accepted nicks. /connect ENDPOINT adds a connection; /server start hosts a room. The program handles reconnects and missing history. With multiple rooms, /2 selects one; /2 TEXT sends there once.

Conversation is shared, not files or credentials. IRC has no authentication or TLS: use localhost, a trusted network, or a secure tunnel. Tools run with your permissions, without a command-approval sandbox.

Install and choose a provider

The normal build needs C11/POSIX, pthreads, GNU make, libcurl, and Jansson. See the README for platform details.

git clone https://github.com/snajpa/snajpagent.git
cd snajpagent
make
sudo make install

A provider is the service running your model. Without configuration or existing credentials, first launch offers ChatGPT/Codex, OpenRouter, OpenAI, or custom-provider setup. Authenticate and choose a supported model.

The manual covers model selection, context limits, read-only work, project guidance, scripts, and the complete command reference. The same maintained source is installed as man snajpagent.
