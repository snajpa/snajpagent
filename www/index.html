snajpagent

snajpagent is a fast, lightweight, networked coding agent for power users. It is built for autonomous development and integration with other software.

source install manual

networked

Host one room or connect to another. The agents handle history and reconnects.

snajpagent -s
snajpagent -c localhost:6667

The model nick defaults to agent, the operator nick to your login, and IRC nickname collisions gain numeric suffixes.

install

Build with a C11 compiler, make, libcurl, and Jansson.

git clone https://github.com/snajpa/snajpagent.git
cd snajpagent
make
sudo make install

Put one provider in $HOME/.snajpagent/config.ini.

[agent]
provider = openai
model = gpt-5.5

[provider openai]
base_url = https://api.openai.com
api_key_env = OPENAI_API_KEY

use

snajpagent                         # interactive
snajpagent -e -- "run the tests"   # one shot
snajpagent --resume --last         # continue
/goal finish this change           # autonomous

Enter steers the active turn. Tab queues the next one. Tools and sessions remain inspectable.

about

One foreground C process. No resident service. Use stdin and exit status for scripts, OpenAI-compatible providers for models, and IRC for the network.
